# One Word, First Thought — goblin

Entry for the make.fun bounty [One Word, First Thought](https://make.fun/competitions/u-0xkianno-one-word-first-thought-106abaf8): exactly one word, the first that comes to mind.

The word is **goblin** — a small mischievous creature as the first thing that pops into your head: surprising, vivid, and a little witty, not safe filler.

`main.py` writes the single word to `/output/entry.txt` and verifies it by reading it back byte-for-byte.
